# OpenChainClaw

OpenChainClaw 是一个融合 Web3 可验证记录能力的透明个人 AI 助手项目。它的第一版目标不是做“能力最强”的 agent，而是验证一个更具体的产品假设：用户是否愿意因为 AI 操作过程透明、可验证、可回溯，而选择使用 OpenChainClaw。

## 项目定位

OpenChainClaw 第一版采用：

**本地 Web 控制台 + 本地 Agent Runtime**

核心能力包括：

- 本地文件读写、网页浏览、API 调用；
- AI 操作时间线与本地审计日志；
- 本地日志哈希与链上可验证记录；
- 高风险操作拦截与用户确认；
- 文件修改前快照与回滚；
- 可选钱包连接与签名确认。

## MVP 边界

MVP 优先实现透明审计层，不追平 OpenClaw、Hermes、Mercury 的全部 agent 能力。

第一版明确不做：

- 企业权限系统；
- DAO 治理；
- 完整多 agent 投票；
- 原始隐私数据上链；
- 浏览器 cookie 或钱包私钥读取；
- 复杂跨设备同步；
- 完整桌面端或移动端。
